# DOT Dynamic Emblem - Mobile Controller App (Android & iOS)

A pure mobile client app (built with React Native & Expo) to control dynamic vehicle emblems like seen in the video demo.

### Clean App-Only Design:
- **No hardware or microcontroller fields** exposed to the user.
- **Pure App Features:**
  - Live Circular Preview stage reflecting the chosen emblem.
  - 8 One-tap presets matching the video (Bugatti EB, Mercedes-Benz, BMW M, OnlyFans, Smiley, Red Airplane, Batman, and BYE BYE hand wave).
  - Custom Graphic Studio with circular 1:1 image picker from the Android phone gallery.
  - Display brightness / Night mode controls.

### How to Run on Android:
1. Extract this zip file.
2. In the folder, run:
   ```bash
   npm install
   npx expo start
   ```
3. Open the **Expo Go** app on your Android phone and scan the QR code, or press `a` in your terminal to launch the Android emulator.
